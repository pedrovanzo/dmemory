# dmemory

A personal memory palace for learnings — captured with the help of LLMs (or sometimes without, but organized and written down with their help).

## What this is

A growing, structured collection of things worth not re-learning twice: technical lessons, notes, decisions and the reasoning behind them, and anything else worth keeping around.

## Public, with private sections

This repo is public, but the memory palace is meant to hold a few private sections alongside the public ones.

**Known open problem:** the frontend side of toggling public vs. private sections is easy. What isn't solved is the actual privacy — if private content is just plain files committed to this public repo, anyone can read them straight from GitHub no matter what the frontend hides. That defeats the purpose. A real design (content kept genuinely out-of-repo, encrypted, or stored separately) is needed before private sections can be considered actually private. Not solved yet — tracked here as a known gap.
